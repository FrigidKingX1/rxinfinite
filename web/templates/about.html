// WHAT IS RXINFINITE

RXInfinite is a community-run server replacement for DiRT Rally 2.0's online services. It lets you create clubs, run custom events, track leaderboards, and keep playing DR2.0 online with a focus on rallycross — RX cars, RX circuits, and the full RX experience.

The local app is a lightweight proxy that intercepts game traffic bound for Codemasters' servers and redirects it to RXInfinite's own backend. No game files are modified — you can uninstall at any time and RaceNet works exactly as before.

// IS IT FREE

Yes. RXInfinite is free and open source. You can create clubs, register, run events, and use all server features at no cost. There are no microtransactions or subscriptions.

// CAN I GET BANNED FOR USING IT

The proxy works entirely on your local machine by modifying your hosts file to redirect traffic — no game memory is read, no game binaries are modified, and no anti-cheat bypass is involved. It is indistinguishable from a network outage as far as the game client is concerned. The original RaceNet service can be restored at any moment by stopping the app or removing the hosts entries.

// WHAT PLATFORMS ARE SUPPORTED

PC (Windows 10/11) and Linux (via Steam Proton). We ship a native Linux binary alongside the Windows .exe. Consoles (PlayStation, Xbox) are not supported.

// HOW DO I INSTALL IT

Head over to our Install page for the full setup guide. It takes just a few minutes.

// CAN I SHOW LIVE INFO ON STREAM

Yes. The desktop app has a Streaming tab that writes plain .txt files (current club, car, location, leaderboard, etc.) to a folder OBS and SimHub can read directly. See the Streaming Overlays page for the full setup and the list of files.
